# 사진으로 알려주는 분리배출 안내 모델

> 26-2 Team 1조 입니다.

아주대학교 2026년 2학기 **기계학습기초** 팀 프로젝트입니다. 단일 물건 사진에서 품목을 분류하고, 공식 분리배출 기준을 확인해 만든 규칙표와 연결하여 배출 방법을 안내하는 개념 증명(PoC) 모델을 목표로 합니다.

**현재 단계: 아이디어 제안 및 데이터셋 선정 준비.** 아래 내용은 [프로젝트 제안서](Team1_proposal.pdf)를 바탕으로 정리한 계획입니다. 아직 학습 코드·데이터·모델·실험 결과는 등록되어 있지 않습니다.

## 1. 프로젝트 개요

물건의 종류를 알아도 버리는 방법을 헷갈리는 문제에 주목합니다. 모델은 물건을 인식하는 데 집중하고, 배출 기준은 별도의 규칙표로 관리합니다.

| 항목 | 계획 |
| --- | --- |
| 프로젝트명 | 사진으로 알려주는 분리배출 안내 모델 |
| 입력 | 단일 물건이 담긴 사진 |
| 예측 대상 | 페트병·플라스틱·유리병·금속캔·종이·비닐·스티로폼·건전지·형광등·음식물·일반쓰레기 등 약 10개 내외 품목 |
| 문제 유형 | 지도학습 기반 다중 분류 |
| 출력 | 예측 품목과 품목별 재활용·일반쓰레기·음식물·전용 수거함 등 배출 방법 안내 |
| 불확실한 입력 | 확신이 낮으면 판단을 보류하고 재촬영 요청 |
| 성공 기준 | 기준선 대비 성능 향상과 전용 수거 품목 재현율 확인 |

품목 클래스와 배출 규칙표는 데이터 확보 및 공식 기준 확인 후 확정합니다. 제안서의 품목 목록은 후보이며, 실제 데이터의 클래스 수를 뜻하지 않습니다.

### 적용 범위와 안내 전제

- 모델은 **품목의 종류만 분류**하며, 오염 여부·오염 정도·라벨 부착 등 물건의 상태는 판별하지 않습니다.
- 배출 안내는 제안서에 명시된 **‘내용물을 비우고 헹군 상태’**를 전제로 하며, 이 조건을 실제 안내 문구에 함께 표시할 계획입니다.
- 품목을 인식했다는 이유만으로 물건의 상태까지 확인했거나 실제 배출 가능 여부를 판정했다고 표현하지 않습니다. 세부 배출 규칙은 공식 기준 확인 후 규칙표에 반영합니다.

```text
단일 물건 사진 → 품목 분류 → 규칙표 연결 → 전제 조건을 포함한 배출 안내
                       └ 확신이 낮으면 판단 보류·재촬영 요청
```

## 2. 데이터셋 및 전처리 계획

### 데이터 후보

| 후보 | 제안서에 정리된 규모·구성 | 활용 계획 및 확인할 사항 |
| --- | --- | --- |
| AI Hub 재활용품 분류 및 선별 데이터 | 약 100만 건, JPG+JSON, 개별 이미지의 상위 범주 9개 | 재활용품·전용 수거 품목 후보. 이용 신청 후 일부 샘플링 검토 |
| Kaggle Garbage Classification | 15,150장, 12개 클래스 | 음식물·일반쓰레기 등 품목 후보. 이용 조건·라이선스 확인 필요 |
| TrashNet | 2,527장, 6개 클래스, 단색 배경 | 보조 데이터 후보. 제안서에는 MIT 라이선스로 기재 |

데이터셋은 **미정**입니다. 위 수치는 제안서에 기재된 후보 정보이며, 실제 확보하거나 최종 채택한 데이터 규모가 아닙니다. 다운로드 주소·버전·라이선스·다운로드 날짜는 선정 과정에서 확인해 기록합니다.

클래스별 **500~1,000장 확보를 목표**로 합니다. 데이터를 결합할 경우에는 클래스 대응 관계를 정리하고, 모델이 품목 대신 출처별 배경 차이를 학습하지 않는지 점검합니다.

### 입력 특징과 전처리

- **전통적 기계학습:** RGB·HSV 채널별 평균·표준편차, 색상 히스토그램, 밝기·대비·선명도·에지 밀도, HOG 등 10개 이상의 수치 피처를 구성할 계획입니다.
- **CNN:** 크기를 통일하고 정규화한 이미지를 입력할 계획입니다.
- 손상·중복 파일을 확인하고 정제 과정을 기록합니다.
- 스케일링 등 학습이 필요한 전처리는 학습 데이터에만 적합하고, 검증·테스트 데이터에는 적용만 합니다.

## 6. 모델 및 실험 계획

### 비교 모델

| 구분 | 모델 | 입력 |
| --- | --- | --- |
| 기준선 | 다수 클래스 예측 | 학습 데이터의 클래스 분포 |
| 기계학습 | 로지스틱 회귀, SVM, 랜덤포레스트 | 수작업으로 추출한 수치 특징 |
| 딥러닝: 선택 과제 | 합성곱 블록 3개의 간단한 CNN | 전처리한 이미지 |

### 공통 분할과 데이터 누수 방지

- **학습:검증:테스트 = 70:15:15**의 층화 분할을 계획합니다.
- 같은 물체의 사진은 같은 분할에 묶고, 이미지 해시로 분할 간 중복을 검사합니다.
- 클래스 분포와 물체 그룹을 함께 고려한 구체적인 분할 방법·seed는 데이터 확보 후 확정합니다.
- 전처리 학습은 train에서, 모델·하이퍼파라미터·확신 기준값 선택은 validation에서 수행합니다.
- test는 모델과 설정을 확정한 후 최종 평가에 사용합니다. 모든 모델은 동일한 분할과 지표로 비교합니다.

### 핵심 비교 실험

1. **특징 구성:** 색상 특징과 색상+질감·형태 특징 비교
2. **모델 비교:** 전통적 기계학습 모델과 선택 과제 CNN 비교
3. **하이퍼파라미터·과적합:** 설정 변경 효과와 학습·검증 곡선 분석
4. **판단 보류:** 확신 기준값에 따른 보류 비율과 정확도의 관계 분석

### 평가와 해석

- **주 지표:** 품목 단위 Macro-F1
- **추가 지표:** 품목 단위 정확도, 배출 방법 단위 정확도
- **별도 관리:** 건전지·형광등 등 전용 수거 품목의 재현율
- **시각화:** EDA·혼동행렬·학습 곡선 등 8개 이상을 목표로 하며, 관찰 내용과 그에 따른 결정을 함께 기록
- **확장 분석:** 특징 중요도·Grad-CAM을 통한 배경 의존성 점검, 출처 간 교차 평가와 색상·밝기 증강, 파라미터 수·추론 시간 비교

**아직 실험을 수행한 결과는 없습니다.** 모델별 점수, 최종 모델, 확신 기준값과 결과 그래프는 실험 후 추가합니다.

팀원 정보와 역할 분담은 추후 작성합니다. 팀원은 [협업 안내](docs/COLLABORATION.md)를, AI 도구는 [AGENTS.md](AGENTS.md)를 먼저 확인합니다.
